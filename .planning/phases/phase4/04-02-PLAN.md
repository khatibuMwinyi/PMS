    Create actions.ts with 'use server' directive:

    - deleteUtilityBill(billId): Owner deletes bill (only if no allocations exist).
    - calculateAllocation(input): Calculates tenant allocations based on method:
      * PER_UNIT: totalAmount / totalUnits per unit
      * PER_PERSON: totalAmount / totalResidents per person
      * PER_SQ_METER: totalAmount / totalAreaSqM per sq meter, then multiply by each unit's area
      Returns: { method, totalAmount, breakdown: [{ unitId, unitNumber, amount }] }
    - saveAllocation(input): Saves allocation results to UtilityAllocation model as JSON.
    - getUtilityBillsByProperty(propertyId): Returns bills for a property.

    Create queries.ts with 'use server' directive:
    - getUtilityBills(ownerId, propertyId?): List bills scoped to owner, optionally filtered by property
    - getUtilityBillById(billId, ownerId): Single bill with allocations
    - calculateAllocation(propertyId, method, params): Calls allocation engine, returns breakdown
    - getTotalUtilitySpend(ownerId, dateRange?): Sum of all utility bills for owner (used in analytics)
    - getUtilitySpendByProperty(ownerId): Grouped by property for charts
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Owner → Utility Bill Form | Owner records bills for owned properties only |
| Allocation Calculator | Calculation results affect tenant billing |
| Utility Reports | Owner views cost breakdown |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07 | Spoofing | Utility bill creation | mitigate | Validate property ownership: bill can only be created for properties where userId = ownerId. Use requireRole('OWNER'). |
| T-04-08 | Tampering | Allocation calculation | mitigate | Calculation is deterministic: same inputs always produce same outputs. Store calculation inputs in UtilityAllocation model for audit. Verify client-side display matches server calculation. |
| T-04-09 | Information Disclosure | Utility bill images | mitigate | Bill URLs stored encrypted (use existing encryption extension). Access controlled: only property owner can view their bills. |
| T-04-10 | Repudiation | Utility allocations | mitigate | All allocation saves logged to AuditEvent: actorId, entityType=UtilityAllocation, oldValue=null, newValue={method, billId, breakdown}. |
| T-04-11 | Denial of Service | Utility bill upload | accept | Low risk: uses existing upload pattern with size limits. Rate-limited by existing rate limiter. |
</threat_model>
