    - getDisputes(userId, role): Returns disputes filtered by user role (owner sees own, provider sees against them, admin sees all)
    - getDisputeById(disputeId, userId): Returns single dispute with full details
    - getProviderStrikes(providerId): Returns strike count and list for a provider
    - getDisputeBacklog(): Admin stats on OPEN/UNDER_REVIEW disputes

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Owner → Dispute Form | Owner submits dispute for completed task |
| Provider → Dispute View | Provider views disputes filed against them |
| Admin → Resolution | Staff reviews and resolves disputes |
| Dispute → Payment Saga | Financial adjustments on resolution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Spoofing | Dispute creation | mitigate | Validate task ownership: only owner of property can dispute tasks on their property. Verify task.completionTime < 24h ago. |
| T-04-02 | Tampering | Dispute resolution | mitigate | Resolution actions require admin role (use requireRole('ADMIN')). Log all resolution actions to AuditEvent. Financial adjustments use existing payment saga with compensation. |
| T-04-03 | Repudiation | Strike application | mitigate | All strike applications logged to AuditEvent with actorId, entityType=Strike, oldValue=null, newValue={providerId, disputeId, reason}. |
| T-04-04 | Information Disclosure | Dispute evidence | mitigate | Evidence URLs stored encrypted (use existing encryption extension). Access controlled: complainant, respondent, and admin only. |
| T-04-05 | Denial of Service | Dispute filing | accept | Low risk: text-based submissions, rate-limited by existing rate limiter (10 req/60s). No file upload directly to dispute (uses existing property image upload). |
| T-04-06 | Elevation of Privilege | Strike threshold | mitigate | Auto-suspension logic runs server-side in resolveDispute action. Provider cannot modify own strike count. Suspension sets User.status = 'SUSPENDED' with audit log. |
</threat_model>
